## The forecast

> Formington: 17°C, sunshine by permit only, rain in triplicate, wind pending approval since March. Please queue.

## Why this one wins

Most forecasts for imaginary cities reach for the same gags — rain falling up, towns blowing away, weather made of food. Formington's weather isn't impossible, it's *administrative*: sunshine needs a permit, rain shows up in triplicate, and the wind has been stuck in approvals since March. It's a real forecast (temperature, conditions, advice) wrapped around one specific, escalating absurdity, and the deadpan closer — "Please queue." — lands the joke without explaining it. In a head-to-head pairing, specificity and a clean punchline beat a generic weird-weather list.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes the one-line forecast (no trailing newline) to `out/entry.txt`, reads it back, verifies it byte-for-byte, and prints its SHA-256. Deterministic: repeated runs produce identical output.
